Metoda Opis
 getElementById("id") dostęp do wszystkich elementów o konkretnej wartości atrybutu id
 getElementByTagName("znacznik ") dostęp do wszystkich elementów o typie znacznika, np. P lub DIV
 getElementByName("nazwa") dostęp do wszystkich elementów o konkretnej wartości atrybutu

Przykład

<!DOCTYPE html>
<head>
<title> Przykłady dostępu do elementów </title>
<meta charset="utf-8">
<style type="text/css">
.wyroznienieCzerwone { color: Red; font-weight: 600; }
</style>
</head>
<body>
<div id="nazwa"></div>
<script>
document.getElementById("nazwa").innerHTML = "Witaj";
document.getElementById("nazwa").className = "wyroznienieCzerwone";
</script>
</body>
